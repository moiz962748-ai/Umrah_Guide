
# Haramain Guide — Umrah & Ziyarat Digital Companion (1447H / 2026)

A modern, responsive Next.js web application designed to serve as the ultimate digital companion for pilgrims undertaking the journey of Umrah and Ziyarat in Makkah Al-Mukarramah and Al-Madinah Al-Munawwarah.

---

## 🌟 Key Features

- **Step-by-Step Umrah Rituals**: Authenticated guides on Ihram, Tawaf, Sa'i, and Halq/Taqsir.
- **In-depth Ziyarat Explorations**: Detailed historical landmarks in Makkah and Madinah complete with geographic insights.
- **Smart Itinerary Planning**: Curated multi-day scheduling tools for a seamless spiritual journey.
- **Accommodation & Packages**: Curated 5-star Haram-view packages and hotel listings.
- **Fully Responsive Design**: Optimized across mobile, tablet, and desktop viewports with a custom brand identity.

---

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript / JavaScript
- **Icons & Assets**: Lucide React / Custom SVGs

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/moiz962748-ai/Umrah_Guide.git](https://github.com/moiz962748-ai/Umrah_Guide.git)
   cd Umrah_Guide

Install dependencies:

Bash
npm install
Run the development server:

Bash
npm run dev
Open http://localhost:3000 in your browser to view the application.

📦 Deployment
This project is optimized for deployment on Vercel:

Push your repository to GitHub.

Import the project into Vercel.

Ensure the Framework Preset is set to Next.js.

Deploy!
